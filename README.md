## 3. Create a free repository

1. Sign in to GitHub, or create a free account at https://github.com.
2. Select the + menu, then New repository.
3. For a personal homepage, name it EXACTLY azgolli6-source.github.io, using your confirmed GitHub username. The repository name must match the account username. If this repository already exists, do not overwrite its files; use a new repository called cybersecurity-portfolio instead.
4. Select Public for free GitHub Pages hosting. Initialize with a README if needed so the repository has a main branch, then choose Create repository.
5. Choose Add file > Upload files. Upload the CONTENTS of the ahmed-portfolio folder, not the folder or ZIP itself: index.html, styles.css, favicon.svg, README.md and .nojekyll. index.html must be at the repository root. On Windows, turn on View > Show > Hidden items if .nojekyll is not visible. It is an intentionally empty file that bypasses Jekyll processing.
6. Commit the upload to main with a message such as “Add cybersecurity portfolio”. If prompted, choose to commit directly to main.

## 4. Enable GitHub Pages

1. Open your repository's Settings tab.
2. Choose Pages in the left navigation.
3. Under Build and deployment, set Source to Deploy from a branch.
4. Under Branch, choose main and /(root), then Save.
5. Wait for the deployment to complete. The Pages settings screen will display the published URL. The Actions tab shows build/deployment progress and errors.
6. For the personal-homepage repository, the address will be https://azgolli6-source.github.io/. For a repository named cybersecurity-portfolio, it will be https://azgolli6-source.github.io/cybersecurity-portfolio/.
7. Open the actual URL shown by GitHub. Relative asset links support either address. You do not need a custom domain or a paid plan. Enable Enforce HTTPS in Pages settings if available.

Official instructions (checked October 21, 2026):
- https://docs.github.com/en/pages/quickstart
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
