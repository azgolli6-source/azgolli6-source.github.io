# Ahmed Zgolli — Portfolio

Static HTML and CSS website for https://azgolli6-source.github.io/.
No build step, paid service, JavaScript or external font downloads required.

## Update the existing GitHub website

1. Extract the ZIP, then open the ahmed-portfolio folder.
2. Open index.html on your computer to preview the design.
3. Open https://github.com/azgolli6-source/azgolli6-source.github.io.
4. Choose Add file > Upload files.
5. Upload index.html, styles.css, ahmed-zgolli.jpg, favicon.svg and README.md directly into the repository root. Keep the existing .nojekyll file. Do not upload the enclosing folder or ZIP.
6. Commit the changes to main. Files with matching names replace the older versions.
7. Wait for the GitHub Actions deployment to finish, then refresh the website. If old styling remains, press Ctrl+F5.

The portrait must be named ahmed-zgolli.jpg and sit beside index.html. Its original pixels are preserved; CSS controls the display crop.

## Design and content

The page uses a dark navy/mint palette, system typography (Bahnschrift headings and Segoe UI body text on supported Windows systems, with system fallbacks), responsive portrait, keyboard-accessible expandable project sections and inline SVG icons. Fonts may differ slightly across devices.

Five projects cover application identity, connected anti-theft sensors, factory quality control, FPGA gesture recognition and STM32 development. Content uses confirmed project descriptions and background. Academic context is retained. No commercial deployment or performance metrics are asserted.

Contact links use the confirmed email, LinkedIn and GitHub profiles. Page metadata includes a title, description and canonical URL. No visitor tracking, forms or paid dependencies are included.
